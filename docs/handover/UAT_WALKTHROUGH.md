# سيناريو الفحص والقبول (UAT) — ألتا هوست (§13)

مدة الجلسة: ~45 دقيقة. يقودها مالك المنتج مع مدير الفندق التجريبي.
كل بند يقابل معيار قبول في §11 — ضع ✓ عند النجاح.

## التحضير
- [ ] دخول بحساب مدير الفندق (hotel_manager)
- [ ] شاشة ثانية بجوال حقيقي لحساب الفني (technician)

## 1) الرسائل والوكلاء (§11-2, §11-3)
1. أرسل من المحاكي (أو واتساب مربوط): «المكيف خربان في غرفة ٢٠٤ وأبي تمديد الإقامة»
2. ✓ الرسالة تظهر في مركز العمليات خلال ثوانٍ، والوكلاء يضيئون بالتسلسل
3. ✓ الصيانة: تذكرة فورية بمهلة SLA. تمديد الإقامة: مسودة رد في قائمة المراجعة — لم تُرسل
4. من صندوق الرسائل اضغط «استلام المحادثة» ثم أرسل رسالة نزيل جديدة
5. ✓ لا يصدر أي رد آلي أثناء الاستلام؛ «إعادة للذكاء» تظهر للمدير فقط

## 2) المعرفة والسياسات (§6-أ, §4)
1. مركز الوكلاء → المعرفة: أضف «مواعيد المسبح» واعتمدها
2. أرسل سؤالاً عن المسبح → ✓ المسودة تقتبس النص المعتمد حرفيًا
3. عطّل وكيل خدمة النزلاء وأرسل شكوى → ✓ تصل للموظفين بلا أي مسودة AI
4. أعد تفعيله → ✓ المسودات تعود

## 3) أوامر العمل (§11-5)
1. أنشئ أمر عمل «تسريب مياه» بأولوية «حرج» وأسنده للفني
2. ✓ حدث تصعيد فوري في مركز العمليات
3. من جوال الفني: بدء التنفيذ → صورة من الكاميرا → إنهاء
4. ✓ الإغلاق يُرفض ويتحول لـ «بانتظار التأكيد»؛ المدير يؤكد → مغلق
5. ✓ كل خطوة في سجل التدقيق

## 4) السمعة الرقمية (§11-6)
1. السمعة الرقمية → ربط الحساب → تحديث التقييمات
2. ✓ تقييم السلامة (١ نجمة) بإطار أحمر وتنبيه فوري
3. عدّل المسودة واضغط «اعتماد ونشر» → ✓ «رد منشور» يظهر — ولا شيء نُشر قبل موافقتك

## 5) استوديو المحتوى (§11-7)
1. هوية العلامة: عبّئ الخدمات والعروض → «توليد أفكار»
2. ✓ الأفكار مبنية على عروضك الفعلية
3. أنشئ → راجع → اعتمد → انشر → ✓ رابط النتيجة يظهر
4. جرّب النشر على مسودة غير معتمدة → ✓ يُرفض

## 6) التخزين (§11-8)
1. الملفات والتخزين: ارفع صورة → ✓ العداد يرتفع بدقة
2. احذف → ✓ سلة المحذوفات (٣٠ يومًا) والاستعادة تعمل

## 7) الصلاحيات والتدقيق (§11-9, §11-10)
1. جرّب فتح بيانات الاعتماد بحساب موظف استقبال → ✓ ممنوع من الخادم (403) لا مخفي فقط
2. سجل التدقيق → ✓ كل ما سبق مسجّل بالفاعل والوقت، والتحقق من السلسلة أخضر
